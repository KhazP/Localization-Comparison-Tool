# Support

This project offers multiple support paths depending on your need.

## Community Support

- Questions and usage help: https://github.com/KhazP/Localization-Comparison-Tool/discussions
- Bug reports: https://github.com/KhazP/Localization-Comparison-Tool/issues
- Feature ideas: https://github.com/KhazP/Localization-Comparison-Tool/discussions/categories/ideas

## Communication Channels

- Discussions: GitHub Discussions (Q&A, Ideas, Announcements)
- Mailing-list style updates: watch Releases and Discussions in GitHub notification settings
- Real-time chat: fast-response support threads in Discussions Q&A
- Forum: Discussions categories serve as the project forum

## Security Reporting

For security issues, use private reporting as described in [.github/SECURITY.md](.github/SECURITY.md).

## Sponsorship

If you want to support ongoing maintenance:

- Funding options: [.github/FUNDING.yml](.github/FUNDING.yml)

## Response Expectations

- Community questions: best effort
- Confirmed bugs: triaged as time allows
- Security issues: prioritized and handled privately first

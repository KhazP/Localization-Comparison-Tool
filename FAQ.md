# FAQ

## What does this tool do?

It compares localization files, highlights differences, tracks missing or changed strings, and helps teams maintain translation quality.

## Who is this for?

Developers, translators, QA teams, and localization managers working with multilingual apps or games.

## Is this project free?

Yes. It is open-source and free to use under the Mozilla Public License 2.0.

## Which platforms are supported?

Windows is primary. macOS and Linux are also supported targets.

## Which file formats are supported?

JSON, ARB, XML, XLIFF, TMX, CSV, YAML, Properties, and RESX.

## Can I contribute?

Yes. Start with [CONTRIBUTING.md](CONTRIBUTING.md).

## Where do I report bugs?

Open an issue: https://github.com/KhazP/Localization-Comparison-Tool/issues

## Where can I ask questions?

Use GitHub Discussions: https://github.com/KhazP/Localization-Comparison-Tool/discussions

## How do I report a security issue?

Use the private process in [.github/SECURITY.md](.github/SECURITY.md).

## Does it support AI translation?

Yes, there is support for AI-assisted translation workflows and provider configuration in settings.
